WINDOWS ইনস্টলার গাইড — Bangla Likho 12.2.0
============================================

ইনস্টল
------
১. BanglaLikho-Setup-12.2.0-x64.exe চালান।
২. Windows SmartScreen সতর্কতা দেখালে "More info" → "Run anyway" চাপুন
   (বিল্ডটি ডিজিটালি সাইন করা নয়, তাই এই বার্তা আসতে পারে)।
৩. উইজার্ডে Install বাটনে ক্লিক করুন। অ্যাডমিনিস্ট্রেটর অনুমতি লাগে না।

ইনস্টলের অবস্থান
----------------
  %LOCALAPPDATA%\Programs\BanglaLikho
অর্থাৎ শুধু আপনার ইউজার অ্যাকাউন্টে, অন্য কারও জন্য নয়।

তৈরি হওয়া শর্টকাট
------------------
- Start Menu → Bangla Likho
- ঐচ্ছিক: Desktop shortcut (ইনস্টলারের টাস্ক), Windows-এর সাথে চালু
  (টাস্ক নির্বাচন করলে একটি Startup শর্টকাট)

আপগ্রেড
-------
নতুন সংস্করণের ইন্সটলার একই ফোল্ডারে আপগ্রেড করে; পুরোনো প্রোগ্রাম ফাইল
স্বয়ংক্রিয়ভাবে মুছে যায়। আপনার সেটিংস, শেখা শব্দ ও স্নিপেট অক্ষত থাকে।

আনইনস্টল
---------
Settings → Apps → Bangla Likho → Uninstall, অথবা Start Menu-র
"Uninstall Bangla Likho"। শুধু প্রোগ্রাম ফাইল মুছে যায়; নিচের ইউজার ডেটা থাকে।

আপনার ডেটা কোথায়
-----------------
  %APPDATA%\Bangla Likho\
    config.json          সেটিংস (DPAPI দিয়ে সুরক্ষিত)
    user_dict.json       আপনার শেখা শব্দ
    context_model.json   কনটেক্সট মডেল
    lexicon-cache.bin    অভিধানের ক্যাশ (মুছলে আবার তৈরি হবে)
    logs\application.log লোকাল ডায়াগনস্টিকস

সম্পূর্ণ রিসেট করতে চাইলে অ্যাপ বন্ধ করে উপরের ফোল্ডারটি মুছে দিতে পারেন।

চালু ও ব্যবহার
---------------
- প্রথমবার চালু হলে উইন্ডো ও ছোট ফ্লোটিং কার্ড দেখা যাবে।
- F10 → বাংলা/English মোড, F9 → ভয়েস টাইপিং (প্রথমবার অনুমতি চাইবে)।
- ট্রে আইকনে ক্লিক করলে ফ্লোটিং কার্ড দেখানো/লুকানো যায়; ডান-ক্লিকে মেনু।
- হেডারের ড্রপডাউন বা Preferences → Appearance থেকে Light / Dark / System বদলানো যায়।

সমস্যা হলে
----------
1. ট্রে আইকন থেকে Quit করে আবার চালান।
2. About পেজ → "Open local diagnostics folder" → application.log দেখুন।
3. অ্যাপ চালু না হলে কমান্ড লাইনে চালিয়ে মেসেজ দেখুন:
   "%LOCALAPPDATA%\Programs\BanglaLikho\BanglaLikho.exe" --self-check

আনইনস্টল করার পরও যদি ট্রে আইকন থেকে যায়: Sign out করে আবার Sign in করুন।
